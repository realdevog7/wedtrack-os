# 💖 WedTrack OS — Ultimate Wedding Planning Suite

**WedTrack OS** is a state-of-the-art, responsive, and comprehensive wedding planning operating system designed to simplify every aspect of modern wedding organization. Built with performance, aesthetics, and user experience in mind, it empowers couples and planners to collaborate seamlessly.

## ✨ Key Features

- **📊 Comprehensive Dashboard & Timeline**: Keep track of countdowns, daily tasks, milestones, and high-priority wedding checklists.
- **👥 Smart Guest Management & RSVP**: Organize guest lists, track RSVPs, manage dietary restrictions, and generate public RSVP portals for easy guest submission.
- **🍽️ Meal & Dietary Menu Management**: Curate wedding menus, track specific dietary needs, and associate meal choices with individual guests.
- **🪑 Automated Seating Arranger**: Drag-and-drop or automatically organize tables and seating charts with visual floor planning.
- **💼 Vendor Hub & Quote Comparison**: Manage vendor contacts, compare quotes, track payment schedules, and store contracts.
- **💰 Precision Budget Tracker**: Monitor expenses across multiple currencies, set priority categories, and analyze budget breakdown with interactive charts.
- **✉️ Automation & Email Campaigns**: Design automated RSVP reminders and blast personalized updates to guests using integrated email workflows.
- **🔒 Protected Admin & Seller Studio**: Includes a secure, PIN-protected administration portal for controlling buyer whitelist access and managing onboarding workflows.
- **📱 Fully Mobile-Optimized**: Designed with responsive layouts, touch-friendly navigation, and adaptive UI elements for on-the-go planning.

---

## 🚀 Technology Stack

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Vanilla CSS + Tailwind Utility Classes (Glassmorphism & Dark Mode)
- **Icons**: Lucide React
- **Charts & Data**: Recharts, PapaParse (CSV Import/Export)
- **PDF & Exports**: jsPDF, html2canvas
- **Cloud & Sync**: Firebase / Firestore Architecture

## 🛠️ Getting Started Locally

1. **Clone or download the project**:
   ```bash
   git clone https://github.com/realdevog7/wedtrack-os.git
   cd wedtrack-os
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```
